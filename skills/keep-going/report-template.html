What the words mean

Five labels, and the rule for each. If something doesn't match one of these rules it doesn't go at the top of the page.

DECIDE
Work has stopped and can't continue until you answer. Something destructive, a new library, or a genuine fork in the road.
BLOCKED
One task got stuck, so it was parked and the rest of the run carried on around it.
ASSUMED
I made a call without asking, because it was cheap and reversible. Each one says how easily it can be undone.
UNCHECKED
Built, but something wasn't verified — and why. A check that didn't run is never reported as passed.
IDEA
Noticed and deliberately not done, so the run doesn't drift and the changes stay reviewable.
