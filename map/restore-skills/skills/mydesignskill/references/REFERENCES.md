# Reference library

Five source designs and what to borrow from each. Recreate all type with the Material/Roboto superfamily; recreate all separation without outline borders.

## 01 — Furniture, warm editorial e-commerce
`01-furniture-warm-editorial.png`
- **Palette:** warm amber/orange gradient, mustard yellow, teal, warm brown, cream.
- **Borrow:** solid colour rectangles offset *behind* product photos for depth; staggered/diagonal image galleries; small uppercase tracked CTAs (`DISCOVER →`); product cards with a `New` tag and almost no chrome.
- **Separation:** colour blocks + whitespace, zero borders.

## 02 — Cortex AI, dark technical SaaS
`02-cortex-dark-technical.png`
- **Palette:** near-black + electric blue gradient bloom.
- **Borrow:** Roboto Mono utility labels (`ACCELERATED ROI`); faint blueprint grid with `+` crosshair intersections as texture; numbered index rows `/01 /02 /03`; pill announcement badge; big stat numbers with mono captions; gradient glow instead of flat black.
- **Separation:** hairline grid + space. The grid is a deliberate texture, not container framing.

## 03 — AcreFlow, clean agritech
`03-acreflow-clean-agritech.png`
- **Palette:** white + fresh green accent.
- **Borrow:** pill eyebrow labels with a green dot (`• About Us`); inline coloured keyword highlights inside body copy; feature cards (icon → title → copy → `Explore Solution >`); stat row over a thin photo band; muted grayscale logo wall; soft rounded data-viz cards (gauge, bars, metric lists); FAQ accordion.
- **Separation:** background fills + soft shadow + radius. Cards have NO outline.

## 04 — PADRA, institutional / legal
`04-padra-institutional.png`
- **Palette:** deep institutional green, photographic hero.
- **Borrow:** centred white headline over an architectural photo; trust stat row with line icons + single vertical hairline dividers; filled + outlined-text CTA pair; `//`-prefixed small-caps eyebrows; testimonial cards with star ratings + avatars; full-width solid green CTA band; structured dual-column About.
- **Separation:** photo bands, colour band, and thin dividers between stats only.

## 05 — Bridgeway, editorial serif finance
`05-bridgeway-editorial-serif.png`
- **Palette:** black / white / deep forest green.
- **Borrow:** large serif display statements mixing roman + italic (recreate with **Roboto Serif/Slab**); corner-bracket registration marks framing the logo; magazine layout with big imagery and generous type; tiny uppercase labels (`WHO WE HELP`); angled/diagonal image crops; restrained bullet lists.
- **Separation:** whitespace + full-bleed imagery + the green CTA colour block.

## Cross-cutting takeaways
Confident large type · one dominant colour + 1–2 accents · eyebrow-label system · real imagery layered for depth · generous whitespace · pill badges + button pairs · stat rows + logo walls for proof · asymmetry and layering · soft low shadows + medium radius. Separation always by space / fill / shadow / colour block — never an outline border.
